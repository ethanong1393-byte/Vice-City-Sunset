# 🌴 Vice City Sunset
Permanent **GTA 6 Vice City** sunset gradient theme and custom home icon for BetterDiscord.
Made by Discord user **`@nvmbyte0_0`** — DMs wide open to people who want custom themes for Discord :)

---

### 📥 How to Install
1. Make sure **BetterDiscord** is installed from **[betterdiscord.app](https://betterdiscord.app)**.
2. Go to the **Releases** section on the right side of this page and download **`ViceCitySunset.theme.css`**.
3. Open Discord and go to **User Settings** > **BetterDiscord** > **Themes**.
4. Click **Open Themes Folder** and drag **`ViceCitySunset.theme.css`** into that folder.
5. Switch back to Discord and toggle **Vice City Sunset** ON (make sure your Discord Appearance is set to **Dark**).
